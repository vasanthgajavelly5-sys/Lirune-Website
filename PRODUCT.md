# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Personal library readers on Windows and Android who want a quiet, distraction-free environment to read digital books (EPUB, PDF, CBZ, FB2, MOBI, and other formats) completely offline without telemetry, ads, tracking, or required accounts.

## Product Purpose
Lirune is an offline reading application for Windows and Android. Its official website serves to showcase the product's actual interface and capabilities, explain format compatibility, make latest release downloads easily accessible (including Microsoft Store and GitHub releases), and enable community support (via Buy Me a Coffee). The website must reflect the experience of a premium digital reading product rather than looking like a generic SaaS landing page.

## Positioning
A calm, private home for your digital library on Windows and Android. Offline-first, zero telemetry, local document indexation, and true respect for the reader's attention and device ownership.

## Operating Context
Visitors discovering Lirune for personal reading, literature, comic books, technical papers, and long-form documents. Evaluating format support, platform features, privacy guarantees, and downloading verified installation packages.

## Capabilities and Constraints
- Static site built with Astro and hosted on Google Firebase Hosting (Spark no-cost plan).
- Clean, fast, accessible web architecture with zero unnecessary client-side runtime bloat.
- Genuine screenshots from running Windows and Android builds only.
- Strict independence of Windows and Android release versions (Windows v5.6.2, Android v4.9.3).
- Must never claim unsupported features or display unreleased local dev builds as stable releases.

## Brand Commitments
- Name: Lirune Reader
- Tagline: "A calm, private home for your library on Windows and Android."
- Supporting message: "Your books. Your library. Your way."
- Default application identity: Deep obsidian slate, paper lilac accents, soft cyan chrome.
- Light and dark themes must both be deliberately designed, balanced, and reflect a calm reading sanctuary.

## Design Priorities
- Strong editorial typography and bookish elegance.
- Excellent visual hierarchy and readable information architecture.
- Thoughtful whitespace, balanced layouts, and asymmetric visual rhythm.
- Distinctive but restrained color combinations (editorial paper tones in light mode, obsidian slate in dark mode).
- Beautiful presentation of actual application screenshots inside authentic device frames.
- High-quality product storytelling with clear, intuitive navigation and grouped dropdowns.
- Consistent design across all website pages.
- Responsive layouts for desktop, tablet, and mobile (360px to 1920px).
- Subtle, purposeful animations respecting `prefers-reduced-motion`.
- Accessible interactions, WCAG AA/AAA contrast, and semantic markup.

## Anti-Patterns to Avoid
- Generic AI-generated landing-page layouts.
- Endless rows of uniform floating cards.
- Excessive gradients, glowing neon effects, and flashy SaaS cliches.
- Unnecessary rounded containers around everything.
- Overloaded, single-row crowded navigation bars.
- Excessive animations, scroll-hijacking, or distracting decorative elements.
- Repeated sections that add no useful information.
- Visual designs that make the website resemble a generic template.
